# Text Chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 无账号的本地角色聊天，百炼千问统一服务。
**Architecture:** Electron 主进程持有独立聊天仓库和单请求控制器；独立回环 HTTP 服务把百炼 SSE 转为受控流事件；React 订阅聊天快照。
**Tech Stack:** 现有 TypeScript、Node HTTP/fetch、React、Zod、Vitest、Playwright。
**Spec:** docs/superpowers/specs/2026-10-23-text-chat-design.md

## Global Constraints
- 用户端无模型配置；不加入账号、支付、语音。
- 每角色 500 条，输入 2000 字，上下文最近 20 条已完成消息，额外总长度限制。
- 一个生成请求；切菜单继续，切角色停止；密钥仅服务端环境变量。
- 工资数据不上传，不改变原有工资存储。

## Review Focus
- SSE 分块切开汉字/行边界：正确组合，不丢字。
- 停止后的迟到片段：不得写入新请求。
- 历史损坏/写盘失败：保留文件并明确提示。
- IME 回车：不得误发送。
- 接口断流无结束标记：标记失败，不误报完成。
