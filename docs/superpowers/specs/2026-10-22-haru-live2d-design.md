# Haru Live2D 看板娘接入设计

状态：待用户审阅。本文件落实已同意的「精致人物画风与表情优先、原地陪伴、Haru 为首个候选」方向；尚未实施或下载模型。

## 目标与范围

在现有 Electron 应用中提供可实际预览的 Haru，改善插画质量、表情和身体细微运动。工资、日历、计划、提醒及成长记录保持原有功能。成功标准是用户可以在角色选择中预览真实模型、试用动作并切换到桌面，而不是仅看到示意图。

当前应用只有 SVG 角色，通过 CSS 变换表达姿态；增加 Live2D 属于新渲染子系统。方案比较：继续加工 SVG 难以达到用户希望的插画与表情质量；采用通用第三方 Live2D 包会增加版本适配层；本次推荐官方 Cubism Web Framework + Core，以独立适配器接入 React，使用官方 Haru 资源并固定经过验证的版本。

## 已核实的模型能力

官方 CubismWebSamples 的 Haru.model3.json 列出：
- 8 个表情（F01–F08）。这些编号不代表已确认的情绪含义，接入时必须实际预览，才能命名或用于场景。
- Idle 组 2 个动作；TapBody 组 4 个动作。
- 物理、姿态、眨眼参数，以及头部/身体命中区域。
- 点击动作包含声音引用。本应用不下载或播放声音，移除运行清单中的声音引用并保留修改记录。
- 清单没有独立的行走、坐下、睡觉动作。本次不宣称支持这些动作，不通过整体平移冒充行走。

## 用户体验

1. 角色设置新增「Haru · Live2D」候选；保留年糕和小沐供切换。升级不自动替换当前角色。
2. 预览展示真实模型，提供「待机」「点击互动」「表情」试用控件。表情采用实际检查后的中文名称；未确认语义时只标「表情 1」等，不编造情绪。
3. 用户选择 Haru 后，桌面角色默认原地陪伴，可通过现有手柄拖动、置顶、隐藏或叫回。Haru 的散步按钮显示不可用及说明「当前模型暂无行走动作」，主进程也禁止其自主位移。原有角色仍遵循原散步偏好，切换回去不会丢失设置。
4. 默认自然眨眼、呼吸和物理摆动；指针在角色窗口内时轻柔转头注视，移出后平滑回正。无全桌面鼠标追踪需求。
5. 点击角色使用已核实的互动动作。完成计划、午休和下班沿用现有事件队列与气泡，以经过预览认可的动作/表情反馈；没有合适专用动作时使用普通反馈，不假称“睡觉”或“坐下”。
6. 保持无声，不添加语音、口型同步、摄像头、麦克风或 AI 聊天。
7. Haru 使用较高的角色窗口（基准约 360×500，最终按模型画幅校准），保证头发、手臂和动作不裁切；适配现有 75%–125% 缩放及小屏边界。固定信息卡仍独立。
8. 现有成长点、解锁记录与选中配饰全部保留。现有 SVG 星星/抱枕不直接贴到 Haru 上；成长页明确提示这些配饰适用于原角色。Haru 完成反馈正常显示，成熟的专用配饰不在本次范围。

## 渲染与事件架构

- Character 保留统一入口，增加 Haru 渲染分支；SVG 分支继续使用原接口。模型能力明确区分支持的动作与配饰。
- HaruRuntime 封装 Core 初始化、模型加载、纹理、参数、表情、动作队列、物理和 WebGL 资源释放，React 负责容器与生命周期，不直接操作底层模型参数。
- 模型清单和资源固定来源与版本；动作映射集中存放，预览控件和业务事件共享映射。实时渲染不写入工资或成长状态。
- 继续使用主进程现有 CompanionEvent 优先级及互动冷却。动画完成后回到待机；提醒优先，不增加第二套成长奖励或提醒计时器。
- 桌面角色与主面板预览分别拥有画布；只有可见且正在使用的画布渲染。目标每秒 30 帧；隐藏、卸载、切换角色时停止循环并释放纹理/模型/监听器。减少动画时关闭循环待机、物理和指针追踪，保留静态表情反馈与气泡。

## 本地资源、安全与失败处理

- Core 从官方 SDK 获取，Framework 与模型使用官方来源，版本兼容性在实施前验证；所有运行资源随安装包本地提供，不依赖 CDN 或启动时联网。
- 当前 CSP 的 connect-src 为 none；新增专用本地资源协议，仅暴露预先列出的 Haru 文件，使用严格白名单，拒绝路径穿越、任意文件读取与网络 URL。CSP 只放行该资源协议，不放开公网，不关闭 webSecurity/contextIsolation/sandbox。
- 模型加载错误、WebGL 不可用或上下文丢失时显示明确错误与「重试」「切回原角色」入口。工资卡和主面板继续可用；不静默把原角色当成 Haru。
- 连续切换角色时取消旧加载，防止异步加载完成后覆盖当前角色。应用退出时释放资源。

## 数据兼容与授权

- 新增角色值需升级状态 schema，提供 v1/v2 到新版本的明确迁移，保留旧版本副本。已有金额、规则、计划、奖励和坐标原样保留，不重算历史金额。新增角色不能通过错误恢复逻辑导致用户数据重置。
- Framework/Samples、Core、模型分别适用不同协议，不将全部素材称为 MIT/Apache 开源。
- 获取与打包前读取对应版本协议和 Haru 个别条件，保留第三方声明、模型来源、修改说明与必要署名。Core 不能从非官方镜像拼装。
- 首个交付目标为用户本机试用，不自动公开发布。如具体授权条件影响分发，先完成可验证的本地预览并明确说明条件，不能以“免费模型”替代许可核对。
- 许可证依据：https://raw.githubusercontent.com/Live2D/CubismWebSamples/develop/LICENSE.md 。官方仓库说明 Core 需从官方 SDK 下载，不在仓库中管理。

## 验收

- 真实模型预览：8 组表情、2 个待机、4 个点击动作逐一核对；记录适合提醒和完成计划的映射，截图并检查动作过程。
- 桌面：切到 Haru 后不自主散步；拖动、置顶、隐藏、叫回正常；切回原角色恢复其原偏好。角色与卡片互不跟随。
- 静音：无音频文件加载、无声音播放，包括点击与业务提醒。
- 外观：浅/深色及 75%/125% 下头发、手臂和全身动作无裁切、透明背景无黑底；预览与桌面不变形。
- 生命周期：反复切换、隐藏恢复、打开关闭预览后无遗留动画循环；加载失败与上下文丢失能恢复或切回。
- 数据：用临时 v1/v2 副本升级、备份导入导出、重启，确认历史工资与成长不变。
- 保留原工资和计划回归；类型检查、构建及打包后离线加载验证通过后才交付安装包。
