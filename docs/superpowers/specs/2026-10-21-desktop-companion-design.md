# 桌面下班伙伴：设计规格

日期：2026-10-21

## 已确认的目标

构建可安装在当前 Windows 电脑上的 Electron 桌面软件。用户明确优先选择视觉和交互效果，不以安装包体积最小化为目标。软件常驻桌面，可置顶，显示下班倒计时和今日预计工资，按天累计收入，支持大小周、节假日及调休，并允许在萌宠和看板娘之间切换。工资模式同时支持固定月薪、日薪和时薪。

## 产品形态与视觉

暂用名称「下班搭子」，可后续修改。包括透明桌面伙伴窗口和独立主面板。

- 桌面伙伴：内置原创萌宠和原创简洁二次元看板娘各一个，使用可缩放分层图形和动画；具有眨眼、呼吸、轻微摆动、点击反馈、上班和下班状态。不依赖外部付费模型或在线 AI 服务。
- 悬浮信息卡：以大数字显示倒计时，下方显示今日预计收入和累计收入；支持拖动、缩放、置顶开关及收起信息卡。置顶针对普通桌面窗口，不承诺覆盖系统安全界面。
- 主面板：今日概览、月度工作日历、收入记录和设置。明暗双主题，奶油白、薄荷绿和淡紫色，清晰字体、圆角、细腻阴影与克制的过渡动画；提供减少动画设置。
- 托盘：显示/隐藏伙伴、打开主面板、切换置顶、退出。关闭主面板默认隐藏到托盘，退出可通过托盘明确执行。开机启动默认关闭，由设置开启。
- 多显示器与缩放：保存窗口位置；显示器断开时将窗口移回可见工作区；支持常见 Windows DPI 缩放。

第一版采用固定原创角色和预设动作，不含实时对话、语音、Live2D 模型导入或角色商城。

## 首次设置与作息

首次运行引导选择工资模式、金额、收入累计起始日期、工作时段、排班规则及角色。金额未设置时显示待设置，不展示虚构的真实收入。所有项目之后均可修改。

默认示例作息为 09:00–18:00，午休 12:00–13:00，仅作为可编辑初始值。支持同一天内的一个工作区间和可关闭的午休；首版不支持跨午夜班次，表单明确校验并提示。累计开始日期默认安装当天，用户可向前修改以补算。

支持双休、单休和大小周。单休可选休息星期；大小周默认大周周六上班、小周双休，用户指定一个大周的周一作为基准，以自然周计算奇偶，不使用年份周数判断，避免跨年错误。

## 日历与节假日

默认时区为 Asia/Shanghai。通过统一日期模块计算当地日期与星期，不依赖 UTC 日期截断。

日期优先级：用户对某日的手动指定 > 已导入的官方节假日/调休记录 > 每周排班。允许关闭官方日历覆盖，以适配公司排班。

打包前查证并内置有正式发布安排的中国大陆年度日历，保留来源链接、年份和更新时间。未发布或未内置的年份显示「节假日数据缺失，当前按常规排班」，不可标为已识别。用户可手动设置单日工作/休息并导入经过校验的年度 JSON 日历。首版不依赖联网即可使用，不假设未来年度已经发布。

状态区分：休息日、上班前、工作中、午休中、已下班。工作日倒计时表示到当天工作结束的实际墙上时间，午休时仍显示到下班的剩余时间，同时标注午休状态；休息日不伪造当天倒计时，可显示下次上班日期。工资进度使用有效工作秒数，午休不增长。

## 工资与累计的明确定义

所有工资展示均为按用户规则计算的预计收入，不表示银行到账或法定工资核算。首版不自动计算税费、社保、加班倍率和带薪休假待遇。

- 固定月薪：某月每日预算 = 该规则的月薪 / 该月排班工作日数；当天按已完成有效工作时间占全天有效工作时间的比例增长。
- 日薪：工作日预算为设置日薪，按有效工作时间比例增长。
- 时薪：按设置时薪乘有效工作时数增长。
- 休息日预计收入为零；无工作日的月份避免除零并显示说明。
- 午休和上班前不增长；下班后停在当天应计金额。金额内部保留足够精度，展示和每日结算统一四舍五入到分。
- 累计总额 = 已结算日期的金额之和 + 今日进行中的金额；分别展示已结算累计与今日进度，避免用户误解。

每个结算日保存日期、日历状态、工资/作息规则版本和最终金额。每个日期只有一笔有效结算，以日期作为唯一键，重复启动不能重复累计。程序运行中跨日或再次启动时，补算累计起始日期之后未结算的历史日期；此功能按排班估算，不将电脑开机时间作为出勤依据。

工资与作息修改默认次日生效，保留历史版本。首次配置建立起始日期起的规则。历史结算默认冻结；用户主动选择重算历史时展示日期范围与覆盖含义，确认后才重算。修改历史日历不会静默改变已结算记录。系统时钟倒退时不产生重复结算，当前日进度重新按当前时间展示。

## 技术结构与数据

Electron 主进程负责窗口、托盘、持久化、配置校验和结算；React + TypeScript 渲染界面；独立纯 TypeScript 模块负责日历、状态和工资计算，便于边界测试。通过窄范围 preload IPC 暴露需要的操作，启用 contextIsolation，关闭渲染层 Node 集成，不加载远程网页内容。

数据写入 Electron userData 目录，包括带 schemaVersion 的设置、规则历史、日历与结算账本。采用临时文件写入后替换，并保留最近一次有效备份；失败时提示保存失败，不假装成功。数据损坏时保留原文件并尝试备份恢复，不能静默清空收入记录。只允许一个实例写入数据。

支持导出/导入完整 JSON 备份。导入先验证版本、金额、日期和结构，提示将替换本机数据，保留导入前备份。导出文件只由用户选择位置，不上传工资或记录。

## 打包与异常处理

使用 electron-builder 生成 Windows x64 NSIS 安装包，支持用户级安装和桌面快捷方式。可另附便携版作为调试与备用交付。未配置签名证书时如实说明安装包未签名，不承诺不存在 Windows 提示。

休眠恢复、系统时间变化、窗口重开时重新计算当前状态。渲染刷新只更新显示，写入仅在设置变更或结算发生时执行。字体、图形和角色资源本地打包；核心功能离线工作。首版不包含自动更新服务。

## 验收标准

1. 安装包构建成功，应用能在本机启动，主面板、透明伙伴、托盘和置顶开关正常工作。
2. 两个角色可切换并保存；动画、点击交互、窗口拖动和信息卡收起可用。
3. 倒计时在工作前、工作中、午休、下班和休息日正确显示，恢复休眠后不会停留在旧状态。
4. 大小周跨年、官方调休与手动覆盖优先级有自动化测试；缺少日历时界面明确提示。
5. 三种工资计算、午休暂停、零工作日、跨日补算、重复启动不重复结算、规则版本冻结均有自动化测试。
6. 配置和记录重启后保留，备份导入导出有效，损坏数据不会无提示丢失。
7. 主面板在明暗主题和常见窗口尺寸下无明显遮挡，桌面窗口在常见 DPI 下可操作。
