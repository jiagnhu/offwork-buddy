# 1.3.2 画质与悬停菜单

用户确认菜单规则：移入角色区域显示，移出隐藏。沿用现有窗口布局，保留键盘聚焦显示和拖动手柄，不改变角色位置。

## 调查与改动

真实Electron测得原画布320×440，显示320×440，DPR1，抗锯齿已开启。新实现为640×880内部渲染后缩回相同显示尺寸；人物原图和大小不变。适用的2次幂纹理生成mipmap并使用三线性过滤；遮罩从Framework默认256提高到1024。最长边2048及GPU上限防止异常高DPI分配过大缓冲。

首次缩放测试也复现旧画布未同步：75%时尺寸差160像素。通过显式displayScale通知以及窗口/DPR监听同步更新；卸载时移除监听、取消待执行尺寸回调，不保持额外循环。
