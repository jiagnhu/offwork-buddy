# 1.1.2 桌面窗口移动修正

用户反馈拖动后整个桌面伙伴消失。只读检查确认本机为双屏（左屏为负坐标），开启置顶，伙伴缩放 120%。程序化移动到用户保存的位置时仍可见，尚未完整复现物理鼠标拖动后的消失。

已复现并修正两个相关缺陷：

- 保存拖动位置会重复调用原生窗口尺寸和置顶设置；现仅在实际变化时调用，开机启动设置同样避免重复写入。
- 两屏交界处使用第一个相交屏幕，可能将主要位于左屏的窗口推回右屏；现按最大相交面积选择屏幕。

统一显示入口会重新校验可见区域、恢复最小化窗口，并在开启置顶时提升窗口层级。适用于主面板按钮与托盘显示入口，不改变用户主动隐藏行为。

验证：先复现失败的多屏边界单测和移动保存原生调用测试，再修正。51 项单测、类型检查、生产构建、6 组桌面测试通过，包括位置保存、窗口找回、置顶与小屏尺寸回归。测试使用隔离数据目录，未修改用户工资或计划数据。真实鼠标拖动后的最终表现仍需用户现场确认。

已生成 1.1.2 NSIS 安装包；另使用打包后的可执行文件运行窗口偏好及移动找回两组测试，均通过。
