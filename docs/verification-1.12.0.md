# 1.12.0 — Stories and long-term memory

Status: complete. Installer built and packaged runtime verification passed on 2026-10-27.

Seven authored personal arcs contain 63 nodes and 21 endings. The joint story contains 12 nodes and 4 endings. Graph exploration reaches every node/ending using real acquired evidence; the joint blackout chain requires all three public, confirmed records. A world groups personal and joint progress, audience-limited evidence and story dialogue. Forks replay history before a selected choice while retaining the original route.

The version 2 chat document atomically owns per-character memory and up to 20 worlds. Version 1 messages migrate without automatic retrospective extraction. Real-life memory uses source quotes, character isolation and bounded local keyword retrieval (8 records / 2400 characters; clicks at most 2 non-sensitive records). Automatic extraction is delayed and cancelled by foreground work. It is not a vector search system, and semantic paraphrases may not be retrieved. Authored scene progression is deterministic; AI intent only proposes a valid action and free-form dialogue does not write arbitrary story facts.

UI: lazy story/memory drawer from chat or character preview; evidence sharing, per-character source/deletion controls, branch/archive/delete saves, pause/resume and joint participant selection. Desktop input keeps the lightweight story entry and action confirmation. Full backup now includes private chats, memories and worlds; old state-only imports preserve them. A journal restores both state and chat if an import is interrupted.
