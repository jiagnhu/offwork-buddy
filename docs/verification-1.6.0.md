# 1.6.0 — 通用版与按时段请假

日期：2026-10-23。

## 行为

- 删除柊亚里沙的角色入口、头像、运行资源及专用加载逻辑。旧设置选中她时迁移至 Haru，保留工资、计划和其他角色昵称。剩余 7 个模型。
- 工作日历支持同一天多个无薪请假时段的添加和删除。重叠区间合并，仅计算与工作时段的交集，排除午休、休息日和带薪法定节假日。
- 月薪正常排班分母不变；日薪和时薪按同一有效工时比例扣减。今天只扣除已经经过的请假时间，未来预计收入提前扣除全天请假。
- 历史记录使用保存的工资规则和日期快照。保存未舍入的原始日薪，避免重复编辑造成分币漂移；旧记录以保存的金额为基准。删除请假恢复原额。
- 请假记录随本地数据和备份保存；历史收入、累计收入、日历预计收入、工资明细同步更新。
- 构建前清理旧的资源输出，防止已删除模型残留在通用安装包。
