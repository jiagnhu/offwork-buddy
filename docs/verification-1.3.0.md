Haru 使用官方 Cubism SDK for Web 5-r.5。完整 SDK SHA256：67064a7fb1812cf502f5c4a03bfe12cc638c75a621bb4acf06bb28763df06ba0。

真实模型预览中逐项点击并截图检查了 F01–F08、Idle 0–1、TapBody 0–3。8 个表情均能渲染，眼睛、嘴部和脸部状态有变化；保留「表情 1…8」标签，不给未经确认的情绪命名。Idle 0 为自然站立，Idle 1 有抱臂姿态；TapBody 中可见抬手、抱臂等上身动作。普通点击、计划完成和提醒统一使用 TapBody 0 加中文气泡，不将它说成专用庆祝、午休或下班动作。无行走动画，Haru 的有效移动模式固定为 stationary，原保存的偏好不变。

## 实施调整及影响

1. SDK 下载期间先执行独立的数据迁移任务，不改变产品范围；影响仅是提交顺序。
2. 官方完整 SDK 下载包本身含音频，但导入器不复制音频到应用。官网维护时依据官方页面的搜索索引文本核对许可，保留原始协议入口和声明；公开发布前需重新核对最新许可。
3. 通过实际 Character 入口和设置预览验证渲染器，未加入产品测试专用路由；跨任务改动共同验收。
4. 官方 Framework 按兼容的非 strict 配置单独编译，再由 Vite 打包；应用代码仍 strict。增加可取消着色器初始化和按画布释放上下文的最小补丁；升级 SDK 时需重新核对该补丁。
