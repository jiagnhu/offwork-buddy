## 实施调整及影响

1. SDK 下载期间先执行独立的数据迁移任务，不改变产品范围；影响仅是提交顺序。
2. 官方完整 SDK 下载包本身含音频，但导入器不复制音频到应用。官网维护时依据官方页面的搜索索引文本核对许可，保留原始协议入口和声明；公开发布前需重新核对最新许可。
3. 通过实际 Character 入口和设置预览验证渲染器，未加入产品测试专用路由；跨任务改动共同验收。
4. 官方 Framework 按兼容的非 strict 配置单独编译，再由 Vite 打包；应用代码仍 strict。增加可取消着色器初始化和按画布释放上下文的最小补丁；升级 SDK 时需重新核对该补丁。

## 验证边界

自动化使用真实 Electron/WebGL 和程序化窗口操作。尚未人工验证跨不同物理 DPI 显示器拖动、真实系统休眠恢复或 Windows 安装向导全过程。此版本用于用户本机试用，安装包不自动运行，不公开发布。

## 最终审查裁定与暂缓小项

- 将60Hz下约20.5fps问题提升为重要：用户明确重视动作效果，修正为稳定约30fps；代价是维护独立帧截止时间。缺失Core导致全局白屏也已通过延迟导入隔离。
- 新追加的提醒、改名、日历收入属于下一批授权任务，当前交付后继续（见 companion-followups-2026-10-22.md）；未将其混入Haru验收。
- 物理DPI、系统休眠和安装向导无法以自动化替代，保留上述验证边界；不声称完成这些人工验证。
- 未公开发布，因此没有把商业分发资格作为本机试用阻塞项；若要发布必须核对适用许可。
- 暂缓小项：事件出现后4秒内切回Haru可能重播一次动作。奖励不重复、无已释放模型访问；日常持续使用不受影响。
