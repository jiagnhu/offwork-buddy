# 下班搭子 1.5.0

## 本次更新

- 五个角色各有倾听、思考、开心、休息四种参数动作。闲置 20–45 秒后轮换，上一段动作完成后重新计时，避免连续相同待机动作。
- 点击在两种回应间交替，完成计划触发庆祝，提醒触发休息动作。Mao、Miara、Rice 的庆祝结合模型原有动作轮换。
- 参数偏移以模型真实范围为限，不写入基础姿势；原有动作和新增动作共用等待规则，避免连续点击重启、待机截断长动作。隐藏时释放运行实例；减少动画时只绘制静态反馈。
- 修复减少动画首次加载时 Pose 未初始化导致 Haru 同时出现两套手臂的问题。
- “伙伴成长”改为“角色空间”：当前角色、五张带实拍立绘的选择卡片、动作预览、独立昵称。移除成长进度、暂不可用配饰与解锁卡片，以及设置中的成长快捷入口、重复角色选择和禁用的活动模式选择器。
- 每个角色可单独设置 1–20 字昵称，概览、桌面和预览同步显示，卡片保留模型原名辅助辨认。Haru 默认名恢复为 Haru，原有自定义昵称保留。
- 保持无声。本次未接入 AI 对话、语音或服装资源。

## 数据兼容

沿用 schemaVersion 3 和旧的内部 growth 导航标识，不改动工资、计划、成长历史或配饰记录。新 characterNames 字段可选，保存时按角色合并，避免覆盖其他角色昵称；Haru 沿用 haruName 字段。首次加载没有 characterNames 的旧数据时建立空映射，将旧默认名称“丝袜妹”迁移为 Haru；其他昵称不变，迁移后的用户仍可自行设置任何合法昵称。

## 资源

五张 PNG 来自本地捆绑 Live2D 模型的透明 WebGL 帧，无网络依赖，随前端打包。可在构建后运行 `node scripts/capture-character-portraits.mjs` 重建，脚本使用独立临时用户目录。模型及截图版权归 Live2D Inc.，随应用现有模型许可分发。
