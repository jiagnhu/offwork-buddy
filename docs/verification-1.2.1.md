# 1.2.1 散步停滞修复

2026-10-22。

复现：120% 大小的角色从上方走向底部，底部路线被信息卡分隔；旧逻辑反复选中信息卡旁的当前位置作为目标，导致每隔20秒重新等待而不转身。固定随机源、负坐标屏、连续模拟3分钟的回归测试在修复前失败（到达底部后水平位移为0）。

修复：信息卡占据底部通道时，将它视作当前可走区域的边界，角色到边界后掉头。保留鼠标靠近暂停、手动拖动停留、静止模式、隐藏与减少动画等规则。

验证：72项单元测试通过，类型检查通过。新增实际Electron窗口多回合散步测试；最终结果与安装包信息见下文。正式用户数据仅只读核对相关偏好设置，未修改。
