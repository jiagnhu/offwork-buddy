# 1.7.5 桌面交互与长回复

## 用户确认的行为
- 气泡不能固定高度或依赖滚动：随内容增高，超过屏幕使用点击分页。
- 初始气泡高度为 135px（原 90px 的 1.5 倍），高度使用 240ms 动画。
- 输入框支持全桌面拖动；移出渐隐至 16% 不透明度，移入使用 450ms 动画恢复。
- 收起时间/计划信息卡后，在角色顶部显示玻璃风格倒计时，仅数字，不显示标题、金额或计划。

## 实现
- 原生窗口按需要预留增长空间，内部气泡动画展开；动画中通过 Windows 窗口形状更新可点击区域，透明空白不会遮挡桌面。
- 动画结束后回收原生窗口高度并重新定位，避免长回复的短末页远离角色。
- 按实际字体与宽度测量分页，Unicode 字符不截断，全部页面拼接可恢复原文；无滚动条。
- 翻页重新给予 10 秒阅读时间，过期回复不会复活。
- 输入框新增原生拖动手柄，首次拖动后与角色位置独立，同次运行收起再打开保持位置。
- 顶部数字沿用午休/下班倒计时；玻璃外观由半透明渐变、背景模糊和细边框实现。
