## 设定的深度

每个人物包含身份与年龄、从早年到当前的时间线、形成性经历、欲望与恐惧、缺陷与自我欺骗、生活习惯、重要物件、主要关系、公开与私密事实、对话风格、示例、未来分歧和连续性硬约束。

“完整人生”指截至故事起点已经发生的生活，不是把未来和死亡全部写死。人物未来可以改变，也可以不悔改；不能让所有人自动被用户感化。

## 面向产品的边界

用户仍只选角色与改昵称。详细档案可选阅读，普通聊天无需了解任何设定。人物的恶意可以在虚构故事中成立，不能赋予应用窃取信息、强迫用户付费或拒绝退出的权限。作者事实与角色说辞分离，避免“角色撒谎”变成“软件胡编”。
