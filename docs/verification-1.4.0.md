# 1.4.0 多角色与拖动修复

用户要求加入 Mao、Hiyori、Miara、Rice，保留丝袜妹，移除年糕和小沐，并修复进入拖动图标时菜单消失。

## 实现

- 角色选择、预览和桌面快捷切换统一使用五角色清单；动作与表情数量来自实际模型文件。Mao/Hiyori/Rice 来自已校验的官方 SDK 5-r.5，Miara 来自官方示例包。完整资源离线打包，导入脚本校验源包和资源哈希，不包含音频。
- 共用现有高清 WebGL 渲染器；支持缺省 Pose/表情文件，切换角色释放旧画布和上下文。Rice 调整站位居中。Miara 的 Tap/Flic 合并为应用互动组，互动单次播放后恢复待机。
- 删除两套 SVG 角色和选择入口。旧 pet/assistant 存档、导入备份及偏好输入统一映射到 haru；工资、计划、成长与既有配饰解锁记录保留。当前五角色不佩戴旧 SVG 配饰。
- 五角色采用原地动画；Miara 保留官方行走/精灵等场景，可在预览中试播，未启用跨桌面自主散步。
- 原拖动区域使用 Electron 原生 app-region，绕开网页指针事件，与 CSS hover 显隐冲突。改为 no-drag 区域、指针捕获和限定来源的拖动 IPC；主进程验证输入并限制在屏幕工作区。按住拖动期间保持菜单，松开/失去捕获后结束拖动。
- Windows 程序移动不保证触发 native moved；实测发现位置未保存后，增加明确的拖动结束保存回调，接入原有串行保存流程。
