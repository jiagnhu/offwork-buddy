# 1.10.0 — AI 角色点击回应

## 行为
- 桌面点击保留即时动作，通过现有 AI 服务生成短句；复用七个角色的性格和用户自定义名称。
- 独立 interaction 请求用途，服务端短回复指令与 160 token 预算；每个角色仅在内存保存最近五句作为去重参考，不写入聊天记录。
- 同一时刻合并连续点击，等待正在生成的正式聊天；新聊天取消点击请求。切换角色、改名称、隐藏桌面与退出时取消未完成回应。
- 正常聊天与通知气泡优先；待显示点击回应只保留最新一条。沿用气泡悬停暂停、离开继续计时、分页机制。
- 失败仅显示明确的 AI 不可用提示，不用固定台词假装 AI 回复。

## 验证
- 163 项单元测试通过，涵盖服务端七种性格、自定义名称、短回复预算、最近台词隔离、取消与失败。
- 独立代码审查发现通知优先级问题，已修复并复查通过。
- 桌面测试使用本地模拟 SSE 服务和临时数据目录，不读取或调用个人 API 密钥。真实上游文案质量仍取决于已配置的模型。
- 首轮聊天回归在既有 Live2D 模型加载检查超过 30 秒，气泡两项通过；最终构建后的复测结果见下。

最终开发构建：类型检查通过；4 项桌面 E2E 全部通过（聊天重试/隔离/持久化、AI 点击气泡悬停、聊天气泡优先、计划通知优先与不污染聊天记录）。
