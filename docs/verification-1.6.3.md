# 1.6.3 共享页面角色实例

2026-10-23。

## 改动

- 今日概览与角色空间使用同一个稳定的 React portal 容器，将容器移动到当前页面的展示位置，保留 Canvas、WebGL 上下文及 Live2D 实例。
- 离开这两个页面时将容器停放到隐藏位置并暂停动画。页面切换中已经开始的加载继续完成，避免取消后重建。
- 角色预览弹窗仍为独立预览；背后的当前角色暂停。实际更换角色会重建共享实例。
- 关闭/隐藏主窗口仍释放图形资源，重新显示角色时按需恢复。
- 概览画布遵守卡片实际高度，避免继承角色通用最小高度后遮挡文字。
