# 1.1.0 更新

- 月薪日预算改为除以当月正常周排班天数；节假日、调休补班和手动覆盖仅影响当天是否工作，不改变分母。已有账本不自动覆写，可在收入记录主动重算。此为出勤收入估算，仍未单独计入带薪假和加班费。
- 小看板移除累计金额和英文标识，今日金额独占一行。
- 倒计时上午指向午休、午休指向下午上班、下午指向最终下班；未设午休时保持下班倒计时。主面板同步同一口径。
- 日历支持按天添加、勾选、取消完成、删除计划；完成项置灰并显示删除线，日期格显示完成进度。
- 计划经过主进程校验并原子保存，随备份导入导出，旧数据自动迁移为空计划列表。

验证：50 项单元测试、TypeScript 检查、生产构建、9 组 Electron 操作测试通过。覆盖午休边界、节假日分母、旧数据兼容、无效计划拒绝、完成/撤销/删除以及重启保留。截图已检查。

NSIS 安装包已生成：`release/OffworkBuddy-Setup-1.1.0.exe`。另使用打包后的可执行文件运行角色操作、每日计划与重启保存两组测试，均通过。安装包未签名。

安装与卸载未在用户账户中实际执行，用户数据没有被测试修改；测试均使用独立临时目录。
