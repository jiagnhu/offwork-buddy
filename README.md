# 下班搭子 / Offwork Buddy

可安装的 Windows 桌面应用：置顶下班倒计时、预计工资与累计记录、工作日历，以及可切换的原创猫咪「年糕」和看板娘「小沐」。Electron + React + TypeScript，所有工资与记录仅保存在本机。

## 使用

安装 `release/OffworkBuddy-Setup-1.3.1.exe`，首次运行填写工资、作息及累计开始日期。主面板可查看概览、工作日历、收入记录与设置。桌面伙伴顶部的点状手柄用于拖动，其他按钮用于切换角色、置顶、折叠、打开主面板和隐藏。关闭主面板后仍驻留托盘；通过托盘「退出」彻底关闭。

支持浅色/深色主题、75%–125% 伙伴大小、减少动画，以及可选开机启动。原角色为本地原创分层 SVG 动画；新增 Live2D 看板娘使用随安装包离线提供的官方模型。

## 1.2.0 桌面陪伴

- 角色与今日信息卡分开：角色沿当前屏幕底部散步，信息卡固定，可独立拖动、收起。鼠标靠近时暂停，离开两秒后继续；手动拖动后保留位置一分钟。工具条可暂停散步或叫回伙伴，减少动画时不自主移动。
- 午休、下班可选择到点或提前 5/10 分钟提示，仅显示气泡，无声音。隐藏整个伙伴时不弹出；旧提醒不补播。
- 今日计划卡显示下一项未完成计划，可勾选或展开全部；与工作日历同步。完成后置灰并加删除线。
- 点击今日收入或历史金额可查看计算明细。历史金额保留原记录，只有主动重算才改变。
- 「伙伴成长」显示成长点与配饰：当天首次互动 +1，完成今日计划 +2，每天最多奖励 5 项。重复勾选不重复奖励，历史/未来计划不奖励。10 点星星、30 点抱枕、60 点特别庆祝，两种角色共享成长。
- 升级时保留旧账本，转换前保存原始 v1 数据副本 state.pre-v2.json；不自动重算历史工资。

## 工资口径

- 今日收入是按用户排班计算的**估算**，不是到账或法定工资核算。不自动计算个税、社保、其他带薪假、加班倍率或真实出勤。日历标注的法定节假日计正常工资。
- 固定月薪除以该版本规则下的当月正常周排班天数（忽略节假日、补班与手动调班），得到每日预算；实际排班决定当天是否增长收入。节假日不再抬高日薪。日薪按每天金额；时薪按有效工作时数。三种模式均在工作期间增长，午休暂停。法定节假日全天按正常日薪计入；调休休息不视为法定节假日，不保证整月估算合计等于月薪。
- 每日结束后结算，重新运行会补算关机期间排班收入，不以开机时长代表出勤。按分四舍五入，因此整月逐日结算之和可能有几分钱的舍入差。
- 工资/作息变更次日生效，历史记录冻结。月中调薪分别使用对应日期生效的工资版本。修改历史日历后，可在收入记录主动选择重算；操作会要求确认。
- 仅支持同日班次，默认 Asia/Shanghai 时区。累计开始日期后续可以向前扩展，不能向后截断已有记录。

## 日历

优先级：单日手动覆盖 > 启用的官方年度日历 > 单双休/大小周。大小周以用户指定的大周周一为基准，跨年继续交替。

点击日期可添加每日工作计划，勾选后置灰并显示删除线，可取消完成或删除。计划保存在本机，并随备份导入导出；旧备份自动补全为空计划。

小看板只显示今日收入。上午倒计时指向午休开始，午休期间指向下午上班，下午指向当天最终下班；未设置午休时直接倒计时到下班。

升级 1.1.0 不自动覆盖已结算金额；需要使用新算法核对历史收入时，在「收入记录 → 调整历史记录」中选择日期重算。

内置 2026 年安排，来源：[国务院办公厅通知](https://www.gov.cn/zhengce/content/202511/content_7047090.htm)，使用[北京市政府转载](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html)核对。未内置年份会提示数据缺失，依常规排班运行，不猜测未来调休。

工作日历页可导入以下格式的 JSON，`true` 表示补班、`false` 表示休息，未列日期使用周排班。导入前应查证官方发布的完整年度安排。

```json
{"2026":{"source":"https://www.gov.cn/zhengce/content/202511/content_7047090.htm","updated":"2026-10-21","days":{"2026-10-01":false,"2026-10-10":true}}}
```

## 备份与恢复

设置页可导出/导入完整 JSON 备份。导入会替换本机数据并保存导入前备份。保存时保留上一份有效数据；主文件损坏时尝试恢复，无法恢复会明确提示并保留原文件。

默认数据位于 Electron 用户数据目录（通常在 `%APPDATA%/下班搭子`；启动错误会展示精确路径）。卸载默认保留数据。备份可能包含工资金额，请自行妥善存放。

## 开发与打包

构建环境要求 Node.js ≥22.12，建议 Node.js 24。不要设置 `ELECTRON_RUN_AS_NODE`，该变量会让 Electron 以 Node 模式运行。

```powershell
npm ci
npm test
npm run typecheck
npm run build
npm run test:e2e
npm run dev
npm run dist
```

`npm run dev` 构建后启动应用；`npm run dist` 生成 x64 NSIS 安装包。构建不自动发布或上传任何数据。安装包未配置商业签名证书。

测试使用独立临时数据目录，不修改用户正式账本。本次验证范围和限制记录在 `docs/verification-1.3.1.md`，原版记录在 `docs/verification.md`。

## 1.3.0 Haru Live2D

在「偏好设置 → 预览 丝袜妹」试用 8 个表情、2 个待机动作与 4 个互动动作，点击「使用 丝袜妹」后切换。预览不增加成长点。Haru 原地陪伴，不会自动散步；原角色仍可使用，并保留原散步与配饰偏好。

模型、运行库、纹理和着色器均随安装包离线提供，保持无声。隐藏窗口时释放动画资源；「减少动画」仅绘制静帧。v1/v2 数据升级前保存原文副本，不重新计算历史工资。模型来源和许可见 THIRD_PARTY_NOTICES.md。此版本用于本机试用，未公开发布。


## 1.3.1 日常陪伴

- 新看板娘默认名“丝袜妹”，可在偏好设置修改（1–20字）；来源与版权仍使用Haru原名。
- 定时休息提醒默认关闭，开启后可保存5–240分钟间隔。从上午、下午上班时间分别计时；午休、下班、非工作日不提醒，隐藏伙伴不弹出，过期提醒不补播。
- 工作日历每天显示收入：历史按账本、今天按当前进度、未来按全天预计；入职前不计薪。内置2026年13个法定节假日显示“带薪”，不将普通周末和调休休息自动计为带薪节假日。历史已结算值保留，主动重算才使用新口径。
- 自定义年度日历可以加入 paidHolidays 字段，例如 `"paidHolidays":{"2026-10-01":"国庆节"}`；同一天也必须在days中标记false。未提供的年份不猜测法定假日。2026日期依据[国务院放假办法](https://www.gov.cn/zhengce/content/202411/content_6986380.htm)与年度通知。
