你可能还想知道。

第一次见面，先把这些告诉你。

支持哪些电脑系统？＋

目前提供 Windows x64 安装包。macOS、Linux、原生 ARM64 和 32 位版本暂未提供。网站会尝试识别你的系统；不能确认时，你可以手动选择并核对架构。

收入数字就是实际到账工资吗？＋

不是。收入按你设置的工资和排班估算，不自动计算个税、社保、带薪假或加班倍率，也不代表真实出勤。请以实际工资单为准。

需要上传工资或注册账号吗？＋

桌面应用不需要注册账号。工资、日历、计划与累计记录保存在本机。你可以在设置中导出备份，备份可能包含工资金额，请妥善保存。

关闭窗口后，搭子还会在吗？＋

关闭主面板后，应用仍驻留系统托盘。可以通过托盘显示桌面伙伴；需要彻底退出时，点击托盘菜单中的“退出”。

如何安装与保留记录？＋

下载并核对安装包后，运行安装程序，按提示选择安装位置。首次打开填写工资与作息。升级前建议在设置中导出备份；卸载默认保留本机数据。
