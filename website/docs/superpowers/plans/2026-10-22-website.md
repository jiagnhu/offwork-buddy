# 下班搭子独立官网 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付年轻时尚、可独立运行且能按设备系统引导真实下载的下班搭子官网。

**Architecture:** website/ 是可整体迁移的静态项目。浏览器端模块负责系统推荐与页面交互，Node.js 脚本负责预览、安装包验证和静态打包。发布配置独立于桌面应用。

**Tech Stack:** HTML、CSS、原生 JavaScript ES modules、Node.js 内置测试与 HTTP 模块；浏览器验收使用可用的浏览器工具。

**Spec:** ../../2026-10-22-website-design.md（用户于 2026-10-22 确认）。

## Global Constraints

- 官网独立放在 website/，运行与构建不得依赖父项目 node_modules 或 Electron。
- 奶油白、薄荷绿、电光紫；主标题“认真生活，下班有搭子。”；所有示例数字明确标为演示。
- 唯一已核实发行包：Windows x64，1.1.2，OffworkBuddy-Setup-1.1.2.exe，115094734 字节。
- 不虚构其他平台安装包、认证、用户数量或评价；识别信息不上传。
- 手机、未知系统、未知架构、检测失败均有清楚说明；手动选择不被异步检测覆盖。
- 安装包不提交源代码 Git；真实线上下载验证完成前不得宣称下载已上线。
- Sites 新站保留默认所有者访问权限；公开权限与自定义域名不在本轮中擅自修改。

## Review Focus

1. iPad 的桌面模式 userAgent 像 Mac：结合触摸点判为移动端（任务 1）。
2. 浏览器高熵信息查询拒绝或长时间不返回：同步回退可用且不覆盖用户手动选择（任务 1、3）。
3. 下载地址返回 200 HTML 错误页：检查内容、字节数与 SHA-256，不仅检查状态码（任务 2、4）。
4. 移出父仓库或含中文空格路径：独立运行，资源路径不依赖父项目（任务 2）。
5. 禁用 JavaScript 或减少动画：仍可获取版本信息，页面不依赖动画呈现内容（任务 3）。

## 文件职责

相对路径均基于 website/。

- package.json：独立的 test、dev、build、verify:download 命令，无产品运行依赖。
- src/index.html、src/styles.css：语义化页面及响应式视觉。
- src/app.js：角色切换、下载选择与检测状态。
- src/platform.js：纯系统判定及推荐函数。
- src/releases.json：唯一版本配置，含 platform、arch、version、filename、bytes、sha256、url。
- src/assets/：独立原创角色 SVG 与图标副本。
- scripts/server.mjs：仅服务站点目录及明确的本地安装包路径。
- scripts/build.mjs：产出 dist/，校验版本配置与复制静态资源。
- scripts/verify-download.mjs：校验下载文件与预期摘要。
- tests/platform.test.mjs、tests/download.test.mjs：Node.js 测试。
- README.md、.gitignore：独立操作说明，忽略安装包、dist 和本地日志。

### Task 1: 系统识别与版本推荐

**Files:** 创建 package.json、src/platform.js、src/releases.json、tests/platform.test.mjs。

**Interfaces:** `detectPlatform({userAgent, platform, maxTouchPoints, architecture, bitness}) -> {os, arch}`；os 为 windows/mac/linux/mobile/unknown，arch 为 x64/arm/x86/unknown。`recommendDownload(device, releases) -> {release, status}`；status 为 recommended/check-architecture/unavailable，release 可为 null。

- [ ] 写失败测试：Windows x64 返回 recommended；Windows 架构未知返回 check-architecture；Windows ARM/x86、Mac、Linux、手机与未知系统返回 unavailable。
- [ ] 加入 iPad 桌面 UA + maxTouchPoints=5 返回 mobile、Android 不被 Linux 分支误判、空 UA 返回 unknown 的断言。
- [ ] 执行 `node --test tests/platform.test.mjs`，确认测试因模块缺失而失败。
- [ ] 实现纯函数与初始版本配置，默认线上 url 为 null；系统检测不做网络请求，不从 Windows UA 缺少 ARM 字样推定 x64。
- [ ] 重跑上述命令，要求所有断言通过；提交该任务文件。

### Task 2: 真实安装包和独立构建预览

**Files:** 创建 scripts/server.mjs、scripts/build.mjs、scripts/verify-download.mjs、tests/download.test.mjs、.gitignore、README.md；更新版本配置及 package.json。

**Interfaces:** `verifyDownload(url, {bytes, sha256}) -> Promise<void>`，内容不符时抛错；server.mjs 从 `INSTALLER_PATH` 读取本地安装包绝对路径，提供 `/downloads/OffworkBuddy-Setup-1.1.2.exe`；未配置时该地址返回 404。构建使用配置中经验证的下载 URL；开发时仅对已存在本地安装包启用下载入口。

- [ ] 写下载校验失败测试：200 HTML、字节数不符、摘要不符及不存在文件均被拒绝；使用本地 HTTP 测试服务和小型固定字节夹具，不反复复制 110 MiB 文件。
- [ ] 执行 `node --test tests/download.test.mjs`，确认失败后实现流式校验及本地下载路由；不暴露父目录或任意磁盘文件。
- [ ] 从真实发行包计算 SHA-256 并填写 releases.json；本地配置通过环境变量指定安装包，不在源码中硬编码个人绝对路径。
- [ ] 实现静态复制构建及相对资源路径；站点脱离父目录仍可启动，下载外部本地文件仅依赖显式 INSTALLER_PATH。
- [ ] 执行 `npm test`、`npm run build`，从预览服务下载真实安装包并比对大小和摘要；单独测试中文空格目录及缺失安装包状态。
- [ ] 文档写清开发、打包、更新版本及线上下载配置；提交该任务文件。

### Task 3: 完整视觉页面与交互

**Files:** 创建 src/index.html、src/styles.css、src/app.js、src/assets/；必要时补充 tests/platform.test.mjs 的状态选择测试。

**Interfaces:** app.js 消费任务 1 函数和 releases.json；手动选择通过本地 `manualSelection` 状态优先展示，任何后到的自动检测结果不得覆盖。预览状态通过站点自身提供的可用下载信息更新入口。

- [ ] 实现奶油白底、超大标题、薄荷绿下载按钮与紫色贴纸；首屏右侧为桌面伙伴演示，展示原有角色资产的独立副本。
- [ ] 完成功能、角色、下载、FAQ、页脚；角色切换显示对应名称与介绍，示例收入和倒计时显式标为演示。
- [ ] 接入同步系统识别和可选高熵架构信息；查询失败保持回退，查询迟到保持手动选择；不确定时使用 check-architecture 文案。
- [ ] 实现所有平台状态和手动选择；无可用包时解释原因且不生成无效链接。关闭脚本时 HTML 保留功能介绍与实际版本说明。
- [ ] 在桌面及手机视口验收导航、FAQ、角色切换、下载触发、溢出、焦点与减少动画；模拟检测拒绝及手动选择后的异步结果。
- [ ] `npm test` 与 `npm run build` 通过后提交页面文件。

### Task 4: 发布、下载验收与交付

**Interfaces:** Sites 发布仅消费官网目录及静态 dist/；下载配置仅消费已验证真实地址，不使用个人磁盘路径作为线上链接。

- [ ] 阅读 Sites 的本地预览及打包发布参考；确认安装包托管方式是否支持 115094734 字节文件。若不支持站点静态托管，查找已授权的发行存储；没有可用存储时明确报告这一实际阻塞，不伪造 URL。
