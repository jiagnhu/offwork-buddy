# 下班搭子独立官网设计

日期：2026-10-22。状态：设计方向已沟通；本文待用户审阅。

## 目标与边界

为下班搭子新增年轻、时尚的中文官网，让访客了解桌面伙伴、查看真实功能，并根据设备系统找到适用的安装包。官网位于独立 website/ 目录，拥有自己的预览、验证和发布入口，可整体移出当前仓库。运行与构建不依赖 Electron 项目，不改动桌面应用及其数据。

## 方案选择

采用静态 HTML、CSS、JavaScript 单页站点：页面以介绍和下载为主，无需后端或账户系统，便于独立托管。相比引入完整 React 工具链，静态方案依赖更少；相比加入下载管理后台，维护成本更低且满足当前单一安装包需求。

## 视觉与信息结构

奶油白背景、深色大标题、薄荷绿主色、电光紫点缀，搭配留白、圆角和少量贴纸元素。使用现有原创猫咪年糕与看板娘小沐的视觉资产；官网保留独立资产副本，不在运行时引用上级目录。

1. 顶部导航：品牌、功能、桌面伙伴、下载。
2. 首屏：主标题“认真生活，下班有搭子。”，简短说明、下载入口及桌面伙伴场景。演示倒计时与金额标注为演示，不暗示读取用户真实工资或作息。
3. 功能区：下班倒计时、收入估算、工作日历与每日计划，准确反映当前应用。
4. 角色区：年糕与小沐切换预览，轻量动画，并尊重减少动态效果设置。
5. 下载区：系统检测结果、推荐信息、所有平台状态、版本、文件大小和安装说明。
6. FAQ 与页脚：本机数据保存、收入估算口径、托盘退出、备份与恢复；不编造下载量、用户评价或认证。

## 下载与系统推荐

已核实安装包：OffworkBuddy-Setup-1.1.2.exe，Windows x64，115094734 字节，约 109.8 MiB。现阶段不存在可供下载的 macOS、Linux 或原生 ARM64 版本。

- Windows：展示现有 Windows x64 下载入口；能够确认 x64 时标为推荐。
- 明确为 ARM 或 32 位设备：提示没有对应原生版本，不宣称已验证兼容。
- Windows 架构未知：写明“Windows x64 版本，请确认系统架构”，不声称已精确识别。
- macOS、Linux：提示当前平台版本暂未提供，同时允许展开全部版本查看 Windows 包。
- Android、iOS、iPadOS：提示请在 Windows 电脑安装，避免将 iPad 识别为 Mac。
- 未知系统或检测失败：展示手动平台选择。手动选择优先于异步检测结果。
- 下载仅由用户点击触发，不自动下载；不提供虚假按钮或指向不存在文件的链接。

优先使用浏览器提供的系统信息，必要时回退到 userAgent；识别结果仅在浏览器本地使用，不上传设备信息。平台识别不等于兼容性保证。

发布信息集中配置，包括版本、平台、架构、文件名、大小、下载地址和 SHA-256。本地交付包含真实安装包的下载服务路径；安装包不提交到源代码 Git。线上必须使用实际可访问的安装包地址，并验证响应内容确为安装包。若站点托管存在单文件限制，安装包单独托管，不能用本机路径替代线上下载地址。尚未获得可用下载地址时，页面明确显示尚未上线，交付报告明确说明缺口。

## 独立工程与部署

website/ 内包含页面源码、独立资源、下载配置、预览与打包脚本、测试和 README。默认使用现有 Node.js 执行轻量脚本；官网可在不安装父项目依赖的情况下运行。构建产物输出到官网自己的 dist/。

使用 Sites 发布时建立独立站点并保留独立托管配置；按工具默认先发布仅所有者可见的版本，交付时说明访问范围。公开访问权限和自定义域名按用户后续明确指示配置。

## 验收

- 电脑与手机布局清晰，无横向溢出，键盘可操作，焦点可见，文本对比度可读。
- 首屏、角色切换、导航、FAQ、平台选择均可操作。
- 覆盖 Windows x64、ARM、32 位、架构未知、macOS、Linux、移动端与未知系统；模拟检测异常及手动选择与异步检测竞争。
- 校验真实安装包大小及 SHA-256，检查下载响应和文件名，确保不是 HTML 错误页面。
- 无 JavaScript 时仍可查看产品说明与当前可用版本。
- 官网从独立目录启动，桌面应用源代码与构建配置不变。
